# Passport Photo Guide

A small static page for lining up a passport or visa photo and making a 300 DPI print sheet (4×6, 5×7, or US Letter). Choose how many copies to put on the sheet. It is meant to be opened in iPhone Safari.

Once GitHub Pages is set to **Deploy from a branch: main / (root)**, the tool is at:

https://mindflaresi.github.io/photo-print/

Photos are processed only on the device. They are never uploaded.

A US 2×2 in photo fills a 4×6 sheet exactly (six copies, edge to edge). A gap would mean fewer photos, and a full sheet has no room for the size label.
