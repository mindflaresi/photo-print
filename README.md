# Passport Photo Guide

A small static page for lining up a passport or visa photo and making a 300 DPI print sheet. It is meant to be opened in iPhone Safari.

Once GitHub Pages is set to **Deploy from a branch: main / (root)**, the tool is at:

https://mubaxer1a.github.io/photo-print/

Photos are processed only on the device. They are never uploaded.
